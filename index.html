Vocal Health Check

// 03
Протокол проверки — 30 сек перед тренировкой

Если красный — отдых, не петь.

1. Говорный голос
«Привет, как дела сегодня?»
✓ Звучит как обычно
✗ Хрипит / тоньше / «не твой»
2. Головной голос
Тихий «woo-oo-oo» на фальцете
✓ Чистый, лёгкий
✗ Не получается / breathy
3. Сирена
Тихая «ng» снизу до верха
✓ Плавно, без срывов
✗ Срывается / «дыры»
4. Ощущения
Сглотни, прислушайся
✓ Ничего не чувствуешь
✗ Першит / боль / «комок»

🟢 Зелёный

Все 4 ✓ — обычная тренировка.

🟡 Жёлтый

Першение — только разогрев 10 мин.

🔴 Красный

Боль / хрипота — полный отдых.
